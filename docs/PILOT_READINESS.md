# پایلوت کنترل‌شده — وضعیت و دروازه انتشار

هدف اعلام‌شده مالک: ایران، اول ابتدایی تا دوازدهم؛ پنج نقش معلم، دانش‌آموز، اولیا، منشی و سوپرادمین. این مشخصات به معنی تأیید حقوقی، علمی یا آمادگی استفاده از داده واقعی کودک نیست. توسعه/تست جاری فقط با حساب‌های مصنوعی است. زمان نگهداری و مسئول/روش احراز سرپرست و رضایت هنوز تعیین نشده است.

## روش drill پشتیبان

ابزارهای MongoDB Database Tools و اتصال محلی لازم است. نوشتن برنامه را واقعاً متوقف کنید؛ متغیر WRITES_PAUSED تأیید اپراتور است و خودش قفل توزیع‌شده نیست.

```sh
# Stop the app and every other writer first.
WRITES_PAUSED=true npm run verify:backup
# Restart application only after checking result=pass.
```

آرشیو در `.private/backups` با directory mode=700 و file mode=600 می‌ماند؛ شامل پاسخ‌ها، hashهای رمز/نشست و دعوت است. وارد Git یا public نشود. اسکریپت فقط دیتابیس تصادفی `hamyar_restore_*` را حذف می‌کند؛ دیتابیس منبع را هرگز بازنویسی یا حذف نمی‌کند. تغییر منبع حین drill یا اختلاف سند/index شکست است. این روش برای پایلوت کوچک و توقف نوشتن است، نه backup پیوسته مقیاس بزرگ. خرابی آرشیو و بازیابی خارج دستگاه هنوز آزموده نشده است.

## استقرار پیشنهادی، اجرا نشده

- `APP_ORIGIN=https://<actual-domain>`، `COOKIE_SECURE=true`، replica set احرازشده خصوصی، Ollama فقط در شبکه خصوصی.
- فرآیند Node را با کاربر محدود و supervisor اجرا کنید. یک پردازش تا تصمیم درباره limiter مشترک؛ IPهای forwarded عمداً به‌عنوان هویت قابل اعتماد پذیرفته نمی‌شوند. کاربران ناشناس پشت adapter سهم محدودکننده محافظه‌کارانه مشترک دارند.
- قالب `deploy/Caddyfile` را با دامنه واقعی و `caddy validate --config deploy/Caddyfile` بررسی کنید؛ health/readiness، TLS و cookie را روی مقصد تست کنید. هیچ استقرار/تغییر DNS در این اجرا انجام نشده است.
- URL دعوت را در access log، analytics یا error tracker ثبت نکنید. logger برنامه query را حذف می‌کند؛ تنظیم proxy/گردآورنده نیز باید بررسی شود.
- `npm run ops:status` خروجی سلامت و مصرف ۲۴ ساعت AI را بدون مشخصات دانش‌آموز می‌دهد. unknown usage هرگز هزینه/توکن صفر تلقی نمی‌شود. این probe جایگزین آزمون واقعی مدل یا سامانه هشدار نیست.
- `npm run smoke:load` فقط روی loopback و ۶۰ health request اجرا می‌شود؛ از آن ظرفیت دانش‌آموز یا inference نتیجه نگیرید.

منابع قالب استقرار: [Next.js self-hosting](https://nextjs.org/docs/app/guides/self-hosting)، [Caddy reverse proxy](https://caddyserver.com/docs/caddyfile/directives/reverse_proxy)، [Caddy HTTPS](https://caddyserver.com/docs/quick-starts/reverse-proxy). این سند تفسیر یا تأیید حقوقی مقررات ایران ارائه نمی‌کند.

اولویت بعدی P5: تصمیم نگهداری و احراز/رضایت، سپس برش اجرایی consent/revocation/recovery/deletion با تست؛ تا آن زمان آمادگی پایلوت با کودکان تأیید نشده است.

## یادداشت ثبت‌نام مستقل (۲ آبان ۱۴۰۵)

حساب دانش‌آموز اکنون می‌تواند بدون دعوت ساخته شود، اما ثبت‌نام آزاد **به معنی احراز سن، رضایت سرپرست یا مجازبودن پایلوت با داده واقعی کودک نیست**. تا تعریف و اجرای فرایند معتبر رضایت، احراز/بازیابی/حذف و سیاست نگهداری، فقط حساب آزمایشی و داده مصنوعی مجاز است. معلم با دعوت محدود به موبایل حساب متصل می‌شود؛ دعوت ایمیلی قدیمی سازگار باقی است؛ این ارتباط مجوز مشاهده داده سایر معلمان نیست.


## وضعیت امنیت جریان درخواست عضویت

عضویت در درس با صدور کد کوتاه‌مدت معلم و تصمیم دستی او انجام می‌شود و اطلاعات دانش‌آموز در صف تأیید فقط برای مالک همان درس نمایش داده می‌شود. تاریخچه تغییرات و کارهای قبلی حفظ می‌شوند. صدور کد و تأیید معلم، جایگزین احراز سن، رضایت معتبر سرپرست، بازیابی هویت و سیاست حذف/نگهداری داده نیست؛ پایلوت عمومی با داده کودک هنوز نیازمند اجرای کنترل‌های جداگانه است.
