# جریان‌ها و طراحی

معلم: ثبت‌نام ← ساخت درس/مبحث/مهارت دلخواه ← ثبت سؤال و پاسخ مرجع و راهنمای تأییدشده ← دعوت با ایمیل و انتقال کد ← پذیرش دانش‌آموز ← انتخاب دانش‌آموز و سؤال‌ها و محدودیت‌ها ← ساخت پیش‌نویس ← انتشار ← گزارش شواهد ← بررسی پاسخ تشریحی.

دانش‌آموز: پذیرش دعوت و ساخت حساب ← ورود ← فهرست تکالیف ← شروع/ادامه ← پاسخ و ارزیابی یا کمک مجاز ← تلاش مجدد تا سقف ← ثبت پایان ← گزارش مستقل/با کمک/در انتظار بررسی.

خطا: درخواست نامعتبر پیام مشخص؛ 401 ورود مجدد؛ 404 برای منبع خارج مجوز؛ محدودیت تلاش 409؛ قطع AI 503 با حفظ پاسخ‌های قبلی. بدون داده، empty state واقعی نمایش داده می‌شود.

UI فارسی RTL، پس‌زمینه #F8FAFC، متن #1F2937، primary #233B8F، secondary #19B7AE، accent #F4B544. سطح شیشه‌ای روشن، فوکوس واضح، label واقعی، موبایل تک‌ستونه. فونت‌های موجود IRANSansXFaNum و Poppins با next/font/local استفاده می‌شوند؛ بدون درخواست به CDN.
