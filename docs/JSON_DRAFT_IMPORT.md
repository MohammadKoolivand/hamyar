# ورود JSON به پیش‌نویس سؤال‌ها

این مسیر برای فایل JSON ساخته‌شده از PDF سؤال، PDF پاسخ و لیست مباحث است. استخراج متن/OCR خودکار در این مسیر انجام نمی‌شود؛ PDFها را ابتدا در جریان فعلی `/exam-import` پردازش یا خارج از برنامه با بازبینی انسانی به JSON تبدیل کنید.

## استفاده در وب
در صفحه تولید سؤال/پیش‌نویس‌ها بخش «ورود دسته‌ای JSON به پیش‌نویس‌ها» را باز کنید، فایل `.json` (حداکثر ۱ مگابایت) را انتخاب کنید یا متن را بچسبانید و روی «ورود JSON به پیش‌نویس‌ها» بزنید.

هر درخواست شامل ۱ تا ۱۰۰ سؤال است. کاربر باید نقش معلم داشته باشد. هر رکورد فقط در `questionDrafts` با `state: "pending_review"` ذخیره می‌شود و **وارد بانک عمومی نمی‌شود**. تأیید یا رد هر سؤال همچنان از مسیر موجود انجام می‌شود.

## نمونهٔ قابل ورود

```json
{
  "questions": [
    {
      "classification": "free",
      "statement": "در مثلث قائم‌الزاویه، کدام رابطه درست است؟",
      "type": "choice",
      "options": [
        "مربع وتر برابر مجموع مربع دو ضلع قائم است",
        "وتر برابر مجموع دو ضلع قائم است",
        "دو ضلع قائم همیشه برابرند",
        "مربع وتر برابر تفاضل مربع دو ضلع قائم است"
      ],
      "reference": "مربع وتر برابر مجموع مربع دو ضلع قائم است",
      "hints": [],
      "skillIds": []
    }
  ]
}
```

برای ارتباط با مباحث واقعی معلم، به جای `classification: "free"` از `topicId` (UUID مبحث موجود در `curriculum`) استفاده کنید. نام مبحث به‌تنهایی شناسه معتبر نیست؛ نباید UUID ساختگی تولید شود. `skillIds` نیز فقط UUID مهارت‌های متعلق به معلم را می‌پذیرد.

- `statement`: صورت سؤال، `type`: یکی از `choice`، `numeric`، `short`، `essay`، `symbolic`
- `reference`: پاسخ مرجع؛ در سؤال `choice` باید **عین متن یکی از گزینه‌ها** باشد، نه شماره گزینه.
- `options`: گزینه‌ها (برای `choice` حداقل ۲ مورد)، `hints`: راهنمای مفهومی بدون افشای پاسخ.
- `source`، `year` و ویژگی‌های دیگر فقط مطابق `questionSchema` در `src/server/domain.ts` قابل استفاده‌اند.
- فرمول، نمودار و سؤال تصویری نیازمند بررسی دستی و ثبت دارایی معتبر در همیار هستند.

در صورت شکست اعتبارسنجی، هیچ بخشی از بسته ثبت نمی‌شود. درخواست‌های تکرارشده با همان کلید idempotency از ثبت دوباره جلوگیری می‌کنند؛ واردکردن مجدد فایل به‌عنوان درخواست تازه در نسخه فعلی الزاماً تشخیص تکرار محتوایی ندارد.
