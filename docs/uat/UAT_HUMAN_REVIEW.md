## سناریوی معلم برای مالک

ورود → انتخاب/ساخت درس → سؤال دستی/پیش‌نویس → بررسی پاسخ مرجع و راهنما (راهنمای خام نامطمئن باید رد شود) → انتخاب پنج سؤال → ساخت و انتشار مأموریت → حل توسط دانش‌آموز → گزارش معلم → تمرین تقویتی → پاسخ مستقل صحیح → بازبینی تاریخچه.

تست خودکار Golden همین مسیر را با HTTP واقعی و داده مصنوعی تکرار می‌کند. در تست تازه UI، شمارنده‌ها، لینک دعوت، فرم نامعتبر و دستگاه دوم مستقل تأیید شدند. نکات قابل‌سردرگمی برای بررسی مالک: روش ورود رمز قبلی از پیش‌فرض OTP جداست؛ مهلت مأموریت موجود نیست؛ با بانک بزرگ ابتدا از فیلتر و انتخاب مجموعه استفاده شود؛ در پیش‌نویس AI، راهنمای نامطمئن حذف یا با راهنمای مفهومی مجاز جایگزین شود. این فهرست «شکست قطعی UX» معرفی نمی‌شود و نیازمند مشاهده کاربر واقعی است.
