## بازیابی و عملیات

فقط DB مصنوعی UAT با توقف دو نویسنده مستقل آن بکاپ گرفته شد؛ ۴۴ collection و ۲۳۴۹ سند به DB تصادفی بازگشت و hash داده/ایندکس برابر بود. DB مبدأ ثابت ماند؛ فقط DB restore همان drill حذف شد. وب و worker UAT دوباره اجرا شدند؛ نشست و گزارش پس از downtime برابر ماندند. آرشیو خصوصی با mode600 بیرون Git است. این گواه ظرفیت/backup منظم سرور مقصد نیست.

مسیر تکرار امن: محیط جدا با env مستقل بسازید، همه نویسندگان همان محیط را متوقف کنید، `WRITES_PAUSED=true npm run verify:backup` را اجرا کنید و سپس سرویس همان محیط را بالا آورید. این اسکریپت روی DB فعلی/واقعی بدون تأیید و توقف نویسندگان اجرا نشود. مسئول عملیات مقصد هنوز تعیین/تأیید نشده؛ سناریوی rollback مقصد اجرا نشده است.
