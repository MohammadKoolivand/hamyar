# معماری و تصمیم‌ها

مرجع: PRD.fa.md نسخه ۲؛ این سند تصمیم اجرای برش اول است، نه ادعای تکمیل تمام P0ها.

## ابهام‌ها و حل موقت

- «همه دروس» دامنه مدل داده است؛ اعتبار ارزیابی همه دروس ادعا نمی‌شود. نوع عددی، انتخابی، متن کوتاه دقیق و تشریحی انسانی در برش اول.
- فرمول شاخص فصل ۱۲ با «تعداد پاسخ صحیح» اشتباه نشود: صورت و مخرج فقط اولین تلاش ارزیابی‌شده هر سؤال؛ پاسخ درست پس از کمک جدا گزارش می‌شود.
- پایان مأموریت و پایان ارزیابی جدا هستند: submitted در حضور pending review؛ completed پس از بررسی همه.
- نام HamYar موقت؛ ورود password و دعوت زمان‌دار تصمیم قابل تغییر است. ارسال ایمیل ندارد؛ معلم لینک را منتقل می‌کند.
- حداقل سن و رضایت سرپرست تعیین نشده: انتشار برای افراد کم‌سن تا طراحی و تأیید رضایت مسدود است؛ توسعه محلی داده واقعی کودک نیاز ندارد.
- زمان نگهداری، حذف حساب، لغو ارتباط و محل میزبانی باید پیش از پایلوت تصمیم و اجرا شوند.
- P0 کامل شامل دفترچه خطا و سنجش پایانی است؛ مستقل در سطح مأموریت پشتیبانی می‌شود، سنجش ضمیمه و mastery کامل مرحله بعد است.
- محتوای معلم خصوصی و تأییدشده توسط خود او؛ بانک عمومی و ۶۰ سؤال علمی هنوز آماده نیست.

## ساختار

پروژه واحد Next.js App Router در ریشه مخزن است. `src/app` شامل صفحه‌ها و Route Handler است؛ `src/components` رابط، `src/server` منطق سمت سرور و `src/lib` نوع‌های مشترک را نگه می‌دارند. لایه سرور یک Modular Monolith با ماژول‌های identity/content/missions/practice/analytics و MongoDB است. ماژول‌های Fastify در همان پردازش Next با inject اجرا می‌شوند و listener جدا ندارند. evaluator registry مستقل از درس است؛ موتور نمادین فعلاً اضافه نشده.

تمام استایل رابط کلاس Tailwind در JSX است؛ globals.css فقط import خود Tailwind را دارد. فونت‌های ارائه‌شده Poppins و IRANSansXFaNum در src/assets/fonts با next/font/local بارگذاری می‌شوند.

MongoDB منبع حقیقت است. هیچ fallback حافظه‌ای برای runtime وجود ندارد. نوشتن تلاش پیش از ارزیابی؛ خطای ارزیابی نتیجه pending review می‌سازد. مصرف کمک و تلاش با update شرطی اتمیک روی assignment کنترل می‌شود. نشست cookie HttpOnly، SameSite=Strict و Secure در production؛ Origin در درخواست تغییر کنترل می‌شود. hash رمز scrypt و token تصادفی با hash در DB؛ rate limit ورود و API.

AI Provider ورودی فاقد جواب مرجع دریافت می‌کند. Mock فقط hint تأییدشده را بازمی‌گرداند. UI نام mock را آشکار می‌کند. تعویض provider با injection؛ adapter ابری و هزینه واقعی هنوز اجرا نشده. گزارش قاعده‌محور به شناسه تلاش و سؤال متصل است، بدون ادعای تشخیص مفهومی.

## مرز عرضه

TLS/reverse proxy، backup/restore، رضایت کودک، حذف داده، بررسی دسترس‌پذیری و تست بار قبل از عرضه لازم‌اند. PWA فقط shell و assetهای عمومی را cache می‌کند؛ API خصوصی offline cache نمی‌شود. ارسال پاسخ آفلاین پشتیبانی نمی‌شود.

## یکپارچه‌سازی تمام‌استک

`src/server/backend.ts` اتصال MongoDB و برنامه داخلی را به‌صورت singleton هر پردازش نگه می‌دارد؛ `src/app/api/[...path]/route.ts` ورودی HTTP و Set-Cookie را به ماژول‌های موجود تطبیق می‌دهد. runtime برابر nodejs و cache API برابر private/no-store است. secrets فقط در سرور و MongoDB باقی می‌مانند. ورودی قدیمی مستقل سرور حذف شده است؛ برنامه فقط با npm run dev یا npm start اجرا می‌شود.
