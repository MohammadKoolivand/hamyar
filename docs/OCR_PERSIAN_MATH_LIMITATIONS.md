# فارسی، فرمول و جهت نمایش در ورود PDF

## اصلاحات این نسخه (۱۴۰۵/۰۸/۲۶)

- پس از استخراج متن، نگارش ی/ک فارسی و الگوهای **قابل اطمینان** نیم‌فاصله («می رود» → «می‌رود»، «کتاب ها» → «کتاب‌ها») اصلاح می‌شوند. متن بین جداکننده‌های LaTeX و URL تغییر نمی‌کند.
- در نمایش سؤال، عبارت‌های LTR مثل `30cm`، `(30cm)` و `x2` با `<bdi dir="ltr">` جدا می‌شوند؛ علامت‌های پرانتز به‌صورت کاراکتری وارونه یا جایگزین نمی‌شوند.
- موتور پردازش برای نشانه‌های ریاضیِ قابل شناسایی هشدار **تطبیق فرمول با صفحه PDF** اضافه می‌کند. ساختار سؤال، مختصات صفحه و تصویر برای بازبینی باقی است.
- قالب‌های LaTeX موجود از مسیر KaTeX با محدودیت‌های امنیتی و نمایش LTR رندر می‌شوند.

## محدودیت صریح

**هیچ تضمین ۱۰۰٪ برای تمام نیم‌فاصله‌ها یا تمام فرمول‌ها وجود ندارد.** Tesseract فارسی/انگلیسی و PDF.js به‌تنهایی Math OCR دقیق برای فرمول تصویری، کسر چندخطی، ماتریس، رادیکال، توان تودرتو یا دست‌نویس نیستند. این نسخه تبدیل حدسی چنین تصویرهایی به LaTeX انجام نمی‌دهد؛ عبارت‌های نامطمئن باید از روی تصویر اصل ویرایش شوند.

## معیار پذیرش مرحلهٔ بعد

برای Math OCR تخصصی باید ابتدا مدل یا سرویس مجاز انتخاب شود؛ خروجی پیشنهادی باید با صحت‌سنج LaTeX، MathML/KaTeX و تصویر برش‌خورده مقایسه شود. در نبود یا شکست مدل، تصویر اصل و هشدار حفظ شود و انتشار خودکار ممنوع بماند. مجموعهٔ آزمون واقعی با انواع فونت، کسر، ماتریس، واحد، توان، پرانتز و نیم‌فاصله برای سنجش نرخ خطا ضروری است.

سنجش CI این نسخه شامل TypeScript، ESLint، تست سریع و Build است؛ نتیجه باید در PR مشاهده شود. تست تصویری جامع OCR واقعی هنوز اجرا نشده است.
