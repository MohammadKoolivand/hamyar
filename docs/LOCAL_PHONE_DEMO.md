# ورود شماره‌محور و حساب‌های آزمایشی هدهد

ورود و ثبت‌نام نمایشی فقط با شماره موبایل و کد یک‌بارمصرف انجام می‌شود. نقش‌های `student`، `teacher`، `parent`، `secretary` و `super_admin` همگی از همین مسیر وارد می‌شوند. ثبت‌نام عمومی فقط معلم و دانش‌آموز را می‌سازد؛ والد باید دعوت مرتبط داشته باشد و حساب‌های دارای دسترسی مدیریتی فقط با عملیات مجاز ایجاد می‌شوند.

## فقط برای توسعه محلی با داده مصنوعی

در فایل `.env` محلی قرار بده:

```dotenv
MONGO_URL=mongodb://127.0.0.1:27017/?replicaSet=hamyar-rs
MONGO_DB=hodhodeh_dev
APP_ORIGIN=http://127.0.0.1:5174
AUTH_OTP_DEV_BYPASS=true
HODHOD_DEMO_SEED_CONFIRM=true
```

با `NODE_ENV=development npm run seed:demo-users`، هشت حساب آزمایشی ساخته می‌شود. این دستور فقط در صورت انتخاب صریح و نام مجاز دیتابیس توسعه، آدرس MongoDB محلی و Origin محلی اجرا می‌شود؛ حساب‌های قبلی را ارتقا نمی‌دهد یا تغییر نقش نمی‌دهد. دفعه‌های بعد اجرا تکراری ایجاد نمی‌کند.

| نقش | شماره تستی |
| --- | --- |
| سوپرادمین | `09000000001` |
| معلم اول | `09000000002` |
| معلم دوم | `09000000003` |
| دانش‌آموز اول | `09000000004` |
| دانش‌آموز دوم | `09000000005` |
| دانش‌آموز سوم | `09000000006` |
| والد | `09000000007` |
| منشی | `09000000008` |

سپس با `npm run dev` وارد شو. برای هر شماره فوق، ابتدا درخواست OTP بفرست و هر کد **شش‌رقمی** را برای همان challenge وارد کن. پیامک واقعی در این حالت ارسال نمی‌شود؛ محدودیت ارسال و انقضای کد حفظ می‌شود. این ورود **اثبات مالکیت شماره نیست** و برای کاربر تست `phoneVerified=false` باقی می‌ماند.

> هرگز این اعداد را برای پیامک واقعی استفاده نکن. برای staging یا production، bypass باید خاموش باشد و ملی‌پیامک واقعی تنظیم شود. اگر flag روشن باشد ولی محیط به‌طور کامل محلی و آزمایشی نباشد، درخواست ورود رد می‌شود.

## سازگاری با حساب‌های قدیمی

برای جلوگیری از قطع دسترسی داده‌های موجود و شکستن ادغام‌های قدیمی، API‌های تاریخی مبتنی بر رمز/ایمیل با همین وصله حذف نشده‌اند؛ **رابط عمومی و رابط مدیر** دیگر آن‌ها را نشان نمی‌دهد. اگر قرار است آن API‌ها هم بسته شوند، ابتدا مهاجرت ایمن شناسه‌های کاربران قدیمی به شماره موبایل را به‌صورت یک تغییر مستقل انجام بده.

## اعتبارسنجی

```bash
npm run typecheck
npm run lint
npm run build
npm test
npm run test:e2e
```

`npm test` و تست مرورگر نیازمند MongoDB Replica Set آزمایشی هستند. اجرای این تست‌ها یا ایجاد کاربران روی دستگاه دیگری، در این بسته انجام نشده است.
