# هدهد — ورود PDF و استخراج اولیه سؤال

## مسیر کاربری

معلم از `/exam-import`، نوع آزمون و مشخصات را وارد می‌کند، PDF سؤال‌ها و در صورت وجود PDF پاسخ‌نامه را انتخاب و «آپلود و استخراج سؤال‌ها» را می‌زند.

در این نسخه، فایل‌ها **واقعاً به سرور ارسال و همان‌جا پردازش می‌شوند**. متن قابل استخراج از PDF و مرزبندی پیشنهادی سؤال‌ها در MongoDB در موجودیت‌های مستقل `exams` و `examQuestionDrafts` ثبت می‌شود. فایل خام PDF دائماً نگهداری نمی‌شود. فایل سؤال و پاسخ‌نامه فقط در حافظهٔ پردازش استفاده می‌شوند، و برای ردگیری hash و نام فایل ثبت می‌شود.

سؤال‌ها در وضعیت `pending_review` باقی می‌مانند. معلم می‌تواند صورت سؤال را اصلاح کند، نوع پاسخ، پاسخ مرجع و مبحث اختیاری را تعیین کند و سپس هر سؤال را تأیید یا رد کند. تنها بعد از تأیید، با `persistQuestion` در `questionVersions` منتشر می‌شود و می‌توان آن را در بانک سؤال و تکلیف به کار برد. پیش‌نویس‌ها به دانش‌آموز نشان داده نمی‌شوند.

## ایمنی و محدودیت

- بارگذاری فقط برای معلم دارای نشست معتبر، از origin مجاز و با محدودیت نرخ درخواست و فایل قابل انجام است.
- سقف هر PDF: ۱۰ مگابایت؛ حداکثر ۴۰ صفحه؛ اندازهٔ کل multipart محدود است.
- امضای PDF و پسوند و MIME بررسی می‌شوند. این جایگزین اسکن بدافزار اختصاصی در محیط عملیاتی نیست.
- PDF.js تنها متن قابل استخراج را می‌خواند. این نسخه OCR اسکن، تشخیص قطعی شکل، بازسازی دقیق فرمول و تولید خودکار پاسخ صحیح ندارد.
- مرزبندی سؤال‌ها براساس الگوی شماره‌گذاری است؛ در غیر این صورت هر صفحه به عنوان پیشنویس کم‌اطمینان باقی می‌ماند. خروجی حتی با confidence متوسط هم نیازمند تأیید انسانی است.
- متن پاسخ‌نامه فقط برای مشاهده و مقایسه معلم حفظ می‌شود؛ هیچ جواب جدیدی حدس زده نمی‌شود.
- ممکن است در فایل‌های چندستونه، RTL یا دارای رسم و شکل، ترتیب استخراج به هم بخورد؛ قبل از تأیید باید با منبع اصلی تطبیق شود.
- نسبت‌دادن سؤال به آزمون رسمی، بر اساس مشخصات واردشده توسط معلم است و تأیید رسمی بودن منبع نیست. پیش از بازنشر عمومی، مجوزهای نشر بررسی شوند.

## API

- `POST /api/exams/upload`: مسیر اختصاصی multipart در Next.js برای upload محدود و استخراج PDF.
- `POST /api/exams/upload-permission`: بررسی حق بارگذاری و محدودیت نرخ درخواست پیش از استخراج سنگین.
- `POST /api/exams/import`: ثبت تراکنشی آزمون و پیش‌نویس‌های استخراج‌شده در Fastify.
- `GET /api/exams` و `GET /api/exams/:eid`: فهرست و جزئیات خصوصی معلم.
- `POST /api/exam-questions/:qid/approve` و `.../reject`: تأیید یا رد هر سؤال.

## تست

`npm ci && npm run typecheck && npm run lint && npm run build && npm test && npm run test:e2e`

تست‌های `exam-extraction.test.ts` و `exam-pdf.test.ts` الگوهای سؤال و خواندن یک PDF مصنوعی واقعی را پوشش می‌دهند؛ `exam-import.test.ts` دسترسی معلم و انتشار با تأیید را بررسی می‌کند. کیفیت استخراج روی دفترچه واقعی اسکن‌شده یا چندستونه هنوز سنجیده نشده است.
